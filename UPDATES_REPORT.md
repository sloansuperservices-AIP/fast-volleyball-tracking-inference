# Volleyball Tracking Pipeline: Updates & Contributions Report (June 2026)

## 1. fast-volleyball-tracking-inference (Integrated)
The core inference pipeline has been synchronized with the latest upstream developments:
- **Ball Radius Estimation:** Integrated into the ONNX inference loop. Uses contour analysis to estimate the physical size of the ball, enabling better distance filtering and 3D trajectory modeling.
- **Enhanced Temporal Context (seq15):** Added support for 15-frame temporal context models, significantly improving tracking stability during long occlusions.
- **Zone 4 Trajectory Analysis:** New specialized analytical tool (`scripts/analyze_zone4_ball_trajectories.py`) for evaluating attack quality and court positioning near antennas.
- **OpenVINO Optimization:** Dedicated runtime (`src/inference_openvino_seq_gray_v2.py`) for accelerated inference on Intel hardware.
- **Orchestration:** `main.py` now supports unified modes for tracking, pose estimation, and analysis.

## 2. GridTrackNet (Architectural Insights)
- **High-Speed Grid Logic:** Achieves **116 FPS** on M1 Pro by transitioning from full-resolution heatmap outputs (512x288) to a compact grid-based output (48x27).
- **Improved Resolution:** Optimized for 768x432 input resolution.
- **Status:** Grid-based post-processing logic has been ported to the local unified inference script.

## 3. vball-net (Training & Research)
- **Experimental Layers:**

  - **Dynamic Transformation (DyT):** Research into spatial-temporal feature alignment.
- **Model Variants:** `VballNetV1` and `VballNetFastV1` utilize depthwise separable convolutions to maintain accuracy on consumer-grade GPUs.
- **Training Repeatability:** New notebooks improve training stability and repeatability across environments.

## 4. TrackNetV4-PyTorch (Framework Support)
- **PyTorch Port:** A complete implementation of the TrackNetV4 architecture in PyTorch.
- **Optimized Loss:** Implements Weighted Binary Cross Entropy for better handling of the sparse ball detection task.
- **Attentional Mechanisms:** Focuses on motion-aware tracking through learned attention.
